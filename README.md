# Smart Calculator

A command-line calculator built using Python. This project was created to practise Core Python concepts through practical implementation.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square Root
- Percentage Calculation
- Floor Division
- Absolute Value
- Factorial
- Square
- Cube
- Input validation using exception handling
- Continuous menu using a while loop
- Handles division by zero and invalid mathematical inputs

## Technologies Used

- Python
- Math Module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:
    python calculator.py

- Variables and Data Types
